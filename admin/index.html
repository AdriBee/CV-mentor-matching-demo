Fill, review, and upload

  1. Fill identity, research, selected publications, grants and mentorship for the directory. Use the cv section for the full CV history, including education, training, appointments, teaching and service.
  2. Use null for unknown values and [] for empty lists. Remove the all-null example entries from unused CV sections. Keep dates as YYYY-MM-DD where required; CV history dates may use year-only text.
  3. Keep status as draft until reviewed. To publish, complete required fields, select research areas from the taxonomy, and set status to approved. Record actual publication authorization in the workflow object. Set approvalMethod = manual, approvalPolicy = cv-admin-v1, publicationAuthorized = true, authorizedBy and reviewedBy = your GitHub username, approvedAt and reviewedAt = the review date. Do not claim mentor consent unless obtained.
  4. Save as content/cv-profiles.json and upload through GitHub’s Add file → Upload files. This file replaces the entire collection: preserve existing entries you want to keep. For edits, start with the current repository file, not the blank template.
  5. Commit to your working branch and check Validate content. After merging to the publishing branch and a successful Pages deployment, approved records appear in the directory.

The template contains no existing researcher data. The full cv section, drafts, evidence and workflow metadata stay private; only approved directory fields are exported. There is no browser sign-in, CV upload, or AI processing on this branch.
